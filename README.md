Project6 (STORM VIEW)

An iOS application developed with Swift and UIKit as part of my iOS development learning journey.

Features

* Displaying data using UITableView
* Loading and displaying images with UIImageView
* Working with app resources using Bundle
* Reading files using FileManager
* Filtering data with loops and string methods
* Navigation between multiple ViewControllers
* User interface built with Storyboards
* Connected UI elements using IBOutlets
* Responsive layouts created with Auto Layout
* Image handling using UIImage
* Safe type conversion using Type Casting
* Clean and readable Swift code

Technologies

* Swift
* UIKit
* Xcode
* Storyboards
* Auto Layout
* FileManager
* Bundle
* UITableView
* UIImageView

What I Learned

While building this project, I practiced:

* Working with the iOS file system
* Displaying lists using UITableView
* Loading images from the app bundle
* Managing view controllers and navigation
* Creating responsive user interfaces with Auto Layout
* Using Swift loops and string operations
* Writing clean, organized, and reusable code
